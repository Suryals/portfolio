# AI Engineer Portfolio - Surya

A modern, Apple-inspired portfolio website designed for Web 3.0 and AI-enabled professionals.

## Features

- **Apple-Designed Aesthetic**: Clean, minimal UI with subtle gradients and smooth animations
- **Web 3.0 Interactive Elements**: Glassmorphism, particle effects, and micro-interactions  
- **Responsive Design**: Fully responsive for mobile, tablet, and desktop
- **AI-Centric Layout**: Optimized for showcasing AI/ML projects and technical expertise
- **Zero Dependencies**: Pure HTML, CSS, and JavaScript - no frameworks required

## Sections Included

1. **Hero Section** - Eye-catching introduction with gradient text
2. **About & Expertise** - Staff Engineer positioning with AI Enablement focus
3. **Projects Showcase** - Visual project cards with hover animations  
4. **Thought Leadership** - Blog posts, research papers, and insights
5. **Tech Stack** - Interactive technology badges
6. **Contact Section** - Clean contact information and social links

## Files

- `index.html` - Main HTML structure
- `style.css` - Core styling and responsive design  
- `enhanced.css` - Advanced Web 3.0 effects (optional)
- `script.js` - Interactive JavaScript for animations
- `README.md` - This file

## Usage

1. Open `index.html` in any modern web browser
2. Customize the content by editing the HTML structure
3. Update colors in `style.css` to match your brand
4. For enhanced effects, include `enhanced.css`

## Customization

### Colors
Edit these variables in `style.css`:
```css
:root {
    --bg-primary: #0f0f11;
    --bg-secondary: #1a1a1d;
    --accent-primary: #6366f1; /* Indigo */
    --accent-secondary: #8b5cf6; /* Violet */
    --accent-ai: #ec4899;      /* Pink for AI theme */
}
```

### Content
- Replace placeholder text with your actual content
- Update project cards with real project details
- Add your social media links and contact information

## Deployment

This portfolio can be hosted anywhere that serves static HTML files:

- **GitHub Pages**: Push to a GitHub repository and enable Pages
- **Netlify**: Drag and drop the folder or connect via CLI
- **Vercel**: Import your repository for instant deployment
- **Local Hosting**: Simply open `index.html` in your browser
